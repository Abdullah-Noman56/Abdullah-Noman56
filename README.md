### 🏆 Featured Security Projects

| Project | What It Actually Does | Stack |
|---|---|---|
| [**Zero-Trust WireGuard Control Plane**](https://github.com/habib-here/Automated-Zero-Trust-WireGuard-VPN-Control-Plane) | 🔐 API-driven WireGuard automation. HMAC-SHA256 hash-chained tamper-evident audit logs with an integrity verification endpoint, `SELECT FOR UPDATE SKIP LOCKED` IPAM, TOTP MFA, Redis token blacklisting, 6-state peer lifecycle | Python, FastAPI, PostgreSQL, Redis, Docker |
| [**SSD TRIM Recovery**](https://github.com/Abdullah-Noman56/SSD-Trim-Recovery) | 🕵️ Forensic tool that races SSD firmware. Hooks TRIM discards with `blktrace` and reads target LBAs before garbage collection zeroes them. Falls back to magic-byte carving with 64-byte chunk overlap. ACPO chain-of-custody reports | Python, blktrace, pytest, reportlab |
| [**AutoVPNGuard**](https://github.com/Abdullah-Noman56/AutoVPNGuard) | 🚨 7-signal behavioural anomaly detection for VPN access. Catches what firewall rules can't: valid creds at odd hours, from odd countries, from 3+ IPs in an hour | pfSense, Python, n8n, Docker, IPinfo API |
| [**Mini-Tor Network**](https://github.com/Abdullah-Noman56/mini-tor-network) | 🧅 3-hop onion routing with telescopic AES-256-CTR and per-hop HMAC. Live MITM bit-flip simulator that triggers circuit teardown and real-time WebSocket alerts | Python, AES-256-CTR, ECDH P-256, Docker, React |
| [**NetShield Lab**](https://github.com/Abdullah-Noman56/NetShield-Lab) | 🛡️ Three-segment WAN/LAN/DMZ network. The DMZ-to-LAN block is the point: pop the web server, reach nothing. Suricata on all interfaces, tuned until alerts actually fired | pfSense, Suricata, Nginx, NAT |
| [**KernelGuard**](https://github.com/Abdullah-Noman56/KernelGuard) | ⚙️ Linux `write` syscall interception. Custom 5.4.1 kernel compiled and booted from GRUB. Same mechanism a rootkit uses for persistence, opposite intent | C, Linux Kernel, GRUB |
| [**CTI Incident Management**](https://github.com/Abdullah-Noman56/CTI-Incident-Management) | 📋 SOC workflow platform: incident intake, classification, priority triage, status lifecycle tracking | Python, Flask, SQLite, Jinja2 |
